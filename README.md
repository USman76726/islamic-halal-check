# Islamic Halal Check — skill for Claude

Навык (skill) для Claude, который в вопросах ислама предупреждает о харамном и сомнительном (шубха) **по мнению учёных-салафов** (аль-Фаузан, Салих Аль аш-Шейх, ар-Рухейли, аль-Албани, Ибн Усеймин, Ибн Баз, Постоянный комитет по фетвам) и предлагает халяльные альтернативы.

A Claude skill that flags haram or doubtful matters according to Salafi scholars and suggests halal alternatives. Responds in the Muslim's language.

## Что он делает
- Проверяет еду, финансы (риба, страхование, крипто), работу, бизнес, контент, акыду.
- Отмечает проблемы пунктом «⚠️ С точки зрения ислама».
- Приводит доводы из Корана и Сунны, не выдумывая цитат.
- Не поддакивает: если вывод основан на личной логике или слабом мнении — говорит прямо.
- Против радикализма, такфира и терроризма.
- Не является фетвой — по серьёзным вопросам советует обратиться к знающему учёному.

## Как установить
**Claude (claude.ai / приложение):**
1. Скачайте репозиторий (зелёная кнопка Code → Download ZIP) и возьмите из него папку `islamic-halal-check`, упакованную в zip.
2. Откройте Claude → Настройки → Возможности (Capabilities) / Skills → «Загрузить навык» (Upload skill).
3. Выберите zip-файл и включите навык.

**Claude Code:** скопируйте папку `islamic-halal-check` в `~/.claude/skills/`.

## Важно
Этот навык — помощник, а не муфтий. Окончательное решение по серьёзным вопросам — у знающих учёных.
